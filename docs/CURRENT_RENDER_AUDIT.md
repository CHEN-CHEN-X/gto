## 影响画面的主要缺陷

1. [高] artwork_flow.fsh 第 20/35 行：fract(angle*3/(2*pi)) 把短弧材质复制三遍。素材是已完成透视、透镜、遮挡与辉光的最终图，不是可平铺盘面纹理。该展开并非原图几何的逆映射，会复制亮斑、改变数字宽高和轨道间距。
2. [高] 第 88 行附近：内盘取样半径乘 1.4，把外盘图样移植到内盘；没有按原图逐条轨道定义对应关系，导致尺度与明暗位置改变。
3. [高] 第 79～102 行：内盘、外盘、视界和横带各自采用硬编码遮罩及不同运动坐标，再依次 mix。过渡区混合不同位置的数字，造成重影、缺口和静动分割。中央横带又覆盖一次，缺乏统一遮挡与材质坐标。
4. [中] 第 32/47 行：额外乘以随角度变化的亮度，改变原图的固定明暗结构。
5. [高] scripts/preview_artwork.py：原图零误差检查调用 strength=0，只能证明静态显示正确，不能证明动画保留原图。整圈闭合测试证明周期性，不证明某个数字沿正确轨道行进。分区像素差证明有变化，拉伸或闪烁也会通过，不能代替视觉质量验收。
6. [维护] 多个历史 Shader 与文档并存、配置注释有旧参数，但它们不是当前混乱效果的直接渲染来源。备用路径也使部分旧相机参数在默认模式下无效。

## 实际 GPU 对照

同尺寸比较原图与开启动画的 t=0 输出：平均 RGB 绝对字节差 19.469；原图亮度大于 30/255 的像素中，约 78.21% 的像素至少一个通道相差超过 20/255。四分之一圈亦存在较大差异。这是诊断字节差，不是“相似度只有 21.79%”之类的感知评分。

证据：效果图/audit_source_fit.png、audit_active_zero.png、audit_visual_fidelity.json。t=0 已偏离，说明不只是速度问题，降低速度不能修复映射。

## 修复依据

应先停止叠加新的局部补丁。将参考图的固定光照/遮挡与移动数字材质分离，为每条实际轨道建立对应的角度和遮挡坐标；避免把包含黑洞轮廓的整张成品图当作平铺素材。先验证一条前景轨道和一条视界轨道：轮廓稳定、字形不拉伸、光斑不复制、标记特征完整绕行。通过后扩展到其他轨道。10 MiB 限制及 0.2 速度偏好继续有效。
