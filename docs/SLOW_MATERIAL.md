# 慢速原图材质版本

按最新截图标注：撤掉不认可的橙色程序字形层，用绿色区域的原图材质旋转方法覆盖内层，并将整体速度降低 80%。

## 修改

- 删除 innerDigits/SDF 字形、静态模糊底光以及规则数字网格。内层现在同样由 diskMaterial 采样原图材质；坐标同比缩放 1.4，避免半径钳制造成径向长条。
- ARTWORK_FLOW_STRENGTH 从 1.0 改为 0.2，外盘周期 300 秒，内盘/视界环周期 150 秒。与上一版相比速度降低 80%。
- 重新选择视界环源材质弧的端点（根据原图径向颜色曲线匹配），将重叠区从 0.15 缩至 0.04 弧度，以减轻拼接处半个数字叠加形成的缺口。仍使用原图局部材质；空间接缝与画面近似需要结合实际观感判断，时间连续性测试不等于所有字形视觉无缝。
- 中央横穿光带加入单独的连续材质移动，固定光带位置；此前这一区域被黑洞保护遮罩留在静态层。
- 离线验证器读取 Java 中真实速度，完整周期检查从 60 秒相应变为 300 秒，避免预览速度与游戏不同。
